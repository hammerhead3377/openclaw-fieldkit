# OpenClaw Field Kit — Quickstart Card (Print & Fold)

**You will need:** Used laptop, internet, \~30 minutes, curiosity.

### Step 0 — Know Your Tier
```bash
free -h && df -h && nproc
```

### Step 1 — Install OpenClaw
Go to the official repo and run the one-liner:  
https://github.com/openclaw/openclaw

### Step 2 — Set Up Channel (Telegram is easiest)
1. Open Telegram
2. Talk to `@BotFather`
3. Create a new bot → copy the token

### Step 3 — Start the Gateway
```bash
openclaw start
```

**Test it:** Send a message to your bot:  
"Hello, I am your sovereign operator."
