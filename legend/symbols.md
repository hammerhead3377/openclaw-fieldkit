# EE Symbol Legend — IEEE 315 / IEC 60617

| Concept              | Symbol                  | Meaning                              |
|----------------------|-------------------------|--------------------------------------|
| Agent Loop           | Op-Amp + Feedback       | Recirculating intelligence           |
| Context Window       | Capacitor               | Stores charge, saturates             |
| Memory Store         | Battery                 | Persistent potential                 |
| Token Flow           | Conductor + Arrow       | Directional data stream              |
| Guardrail            | Diode                   | One-way, blocks reverse              |
| Validation           | AND / NAND Gate         | Conditional pass                     |
| Tool Dispatch        | SPDT Relay              | Controlled branch                    |
| Fallback             | Multiplexer             | Model selection                      |
| Hard Abort           | Fuse                    | Sacrificial stop                     |
